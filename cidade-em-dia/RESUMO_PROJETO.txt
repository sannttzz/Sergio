🚀 EXECUTANDO O PROJETO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Pré-requisitos:
   • Java 17+
   • Maven 3.6+
   • MySQL 8.0+

2. Criar banco:
   mysql> CREATE DATABASE cidade_em_dia;

3. Compilar:
   $ mvn clean install

4. Executar:
   $ mvn spring-boot:run

5. Acessar:
   http://localhost:8080
